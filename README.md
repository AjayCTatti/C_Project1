# Banking Management System

A simple Banking Management System developed using C programming.

## Features

- Create account
- Display account details
- Search account
- Deposit money
- Withdraw money
- Check balance
- Modify account details
- Close account

## Project Files

- `Main_File.c` – Main banking system program
- `Privacy_File.c` – Handles privacy-related functions
- `README.md` – Project documentation

## Technologies Used

- C Programming
- File Handling
- Structures
- Functions

## Account Limit

The system supports up to 100 accounts.
